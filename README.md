# Secure File Encryption and Decryption System

## About the Project

This is a Computer Network Security (CNS) mini project developed using Python. It protects files through password-based encryption and provides a simple graphical user interface.

## Features

- Multiple file selection
- Password-based file encryption and decryption
- Password strength checker
- Strong password generator
- Progress bar
- Recent activity display
- File integrity checking and tamper detection

## Technologies Used

- Python
- Tkinter
- Cryptography (Fernet)
- PBKDF2-HMAC-SHA256
- SHA-256
- PyInstaller

## Installation

1. Install Python.

2. Download or clone this repository.

3. Install the required library:

   `pip install -r requirements.txt`

4. Run the application:

   `python gui.py`
